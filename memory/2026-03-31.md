## 프로젝트 조사: 고하중 AMMR 개발

### 제임스 요구사항
- 양팔 (Dual-arm) Manipulator
- AMR 적재능력 ≥ 600kg
- 각 팔 가반중량 ≥ 30kg
- 자율주행 (SLAM 등)

### 경쟁업체 조사 (1차)
- **MiR + Universal Robots (MC600)**: 단팔, AMR 600kg + UR30(30kg)
- **KUKA (KMP 600P / KMP 1500P)**: AMR만, manipulator 별도
- **OTTO Motors (OTTO 1500)**: 1500kg AMR, manipulator 없음
- **FANUC (M-2000)**: 최대 900kg 로봇팔, 모바일 통합 초기

### ROKAE (珞石) 심층 조사
- **xMate CR35 시리즈**: 최대 45kg 가반중량, 2246mm 작업반경 (2025 신제품)
- **CMR 복합 로봇**: AMR 적재 500kg, SLAM, 7시간 배터리
- **Helios**: 양팔 휠 로봇, 단팔 5kg (경량 작업용)
- **핵심**: CR35 × 2 = 90kg 총 가반중량 가능하나 통합 제품은 미출시
- ROKAE의 600kg AMR은 없음 (500kg이 최대) → 600kg 이상 자체 개발하면 차별화

### 한국: Rainbow Robotics RB-Y1
- 양팔 모바일 매니퓰레이터, 단팔 3kg (경량)

### 시장 기회
- "양팔 + 30kg+ + 600kg AMR" 통합 제품이 시장에 아직 없음 → 블루오션
- ROKAE가 가장 가까운 경쟁자 (구성요소는 이미 보유)
